MODIFICATIONS (CC-BY-4.0 requires these be indicated)

Adapted for RetroXR as n64dd_disk.glb by Tools/glb/prepare_64dd.py:

  * Converted from a Unity AssetBundle to glTF with ugc-to-gltf
    (https://github.com/XenuIsWatching/ugc-to-gltf).
  * The two bundles are the same mesh with different colour maps, so one GLB
    is shipped with the plain map bound (n64dd_disk_color.png) and the blue
    one beside it (n64dd_disk_color_blue.png) for a runtime swap.
  * REMOVED the "Desync" sticker quad and its texture, and the socket empty.
  * Rotated into RetroXR's floppy frame: label +Z, shutter +Y.
  * Node 64disk renamed Shell; media_label is kept as the swappable label face
    RetroXR lays scraped art onto (see cartridge.gd).
  * Textures written as PNGs beside the GLB.
